# Kit do Criador

Programa para Windows com três ferramentas: baixar vídeos e músicas de vários sites, comprimir/converter vídeos e remover o fundo de fotos.

**Baixar:** [Kit-do-Criador.exe](https://github.com/outlier-apps/kit-do-criador/releases/latest/download/Kit-do-Criador.exe)

Precisa de uma chave de ativação, vendida na Basefy.

## Requisitos

- Windows 10 ou 11 (64 bits)
- Internet (para ativar a chave)

## Como usar

1. Baixe e abra o `Kit-do-Criador.exe`. Ele cria um atalho na Área de Trabalho.
2. Cole a chave de ativação e clique em **Ativar**.
3. Escolha a aba (Baixar, Vídeo ou Fundo) e siga as instruções da tela.

Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.

O programa avisa sozinho quando sai uma versão nova.

## Componentes de terceiros

Este programa inclui o [FFmpeg](https://ffmpeg.org) (licença GPL), cujo código-fonte está disponível em https://ffmpeg.org/download.html, o modelo IS-Net/DIS (Apache 2.0) e o ONNX Runtime (MIT) e usa o [yt-dlp](https://github.com/yt-dlp/yt-dlp) (Unlicense).
